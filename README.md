# ☕ Café Azzura — Customer Website

Website pelanggan Café Azzura. Dibangun dengan React + Vite + Framer Motion.

## Repositori Terkait

| Repo | Deskripsi | Link |
|------|-----------|------|
| **caffe-backend** | API Backend | https://github.com/dypras666/caffe-backend |
| **caffe-admin** | Admin Panel | https://github.com/dypras666/caffe-admin |
| **caffe-ui** | Customer Website (repo ini) | https://github.com/dypras666/caffe-ui |

## Tech Stack
- React 19 + Vite
- Framer Motion (animasi)
- Menu, Booking, Virtual Tour, Blog, Member Portal

## Setup

```bash
cp .env.example .env   # isi VITE_API_URL
npm install
npm run dev            # port 5174
```

## Environment Variables

```env
VITE_API_URL=http://localhost:3002
```
